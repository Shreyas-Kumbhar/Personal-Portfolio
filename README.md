## ✨ Features

- **Cinematic UI/UX:** Stunning visual effects with a custom cursor, canvas-based particles (sparks, dust), and spotlight elements.
- **Glassmorphism Design:** Modern translucent cards and sections.
- **Interactive Animations:** Tilt cards, typing effects, pulse buttons, scroll reveals, and 3D perspectives.
- **Responsive Layout:** Fully optimized and visually consistent across desktop, tablet, and mobile devices.
- **Contact Form:** Integrated contact section for direct communication.

## 🛠️ Built With

- **HTML5** - Semantic and accessible structure
- **CSS3** - Custom styling, Flexbox, CSS Grid, animations, and glassmorphism UI
- **JavaScript (Vanilla)** - DOM manipulation, canvas particle effects, and interactive scroll/mouse animations
- **FontAwesome** - Icons integration
- **Google Fonts** - Bebas Neue & Inter

## ⚙️ Running Locally

To run this portfolio on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Shreyas-Kumbhar/Personal-Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Personal-Portfolio
   ```
3. Open `index.html` in your favorite web browser or use an extension like VS Code Live Server.
